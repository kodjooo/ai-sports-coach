# Prompt-eval харнессы

Проверки КАЧЕСТВА промптов через реальные вызовы LLM. **Стоят денег на API**, поэтому
запускаются РУКАМИ (не в CI), после крупных изменений промптов/каталога/моделей.

## Что проверяют

- `run_plan_eval.py` — 5 профилей людей → `generate_plan` → авто-проверки:
  ровно `per_day` упражнений, все дни, 0 упражнений вне палитры, 0 нарушений инвентаря,
  новичку нет плиометрики, при боли в колене нет прыжков/выпадов/приседов, есть работа спины.
  **PASS**: 0 критических нарушений у всех + ≥4/5 профилей полностью чистые.
- `run_food_eval.py` — блюда с ориентиром ккал → `analyze_food_text` + `refine` → ошибка калорий.
  **PASS**: медиана |ошибки| ≤ 25% и нет систематического занижения (медиана со знаком ≥ −15%).

## Запуск (в контейнере с реальным OPENAI_API_KEY)

Локально/на сервере, где поднят бот:

```bash
docker compose exec -T bot python -u - < tests/prompt_eval/run_plan_eval.py
docker compose exec -T bot python -u - < tests/prompt_eval/run_food_eval.py
```

Профили плана продублированы инлайн в `run_plan_eval.py` (чтобы скрипт был самодостаточным
при запуске через stdin); канонический список — в `profiles.py`.

Детерминированные тесты (без API, для CI) — в `tests/test_*.py`, запуск:
`docker compose --profile test run --rm tests`.
